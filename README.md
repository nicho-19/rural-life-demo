# Rural Life Demo

Godot 4 农村经营游戏 demo。

## 操作

- 移动：`WASD` 或方向键
- 面向农田交互：`E` 或空格
- 鼠标交互：点击底部种子格选择种子，点击农田格开垦/种植/浇水/收获
- 选择种子：`1` 萝卜，`2` 土豆，`3` 白菜，`4` 玉米
- 商店：`B` 打开/关闭种子商店
- 睡觉 / 下一天：`N`
- 出售：`M` 出售背包里的全部成熟作物

## 当前循环

1. 开垦空土地。
2. 选择萝卜、土豆、白菜或玉米种子。
3. 在已开垦土地上种植。
4. 每天浇水，按 `N` 进入下一天。
5. 作物成熟后收获。
6. 按 `M` 出售作物，用金币在商店购买更多种子。
