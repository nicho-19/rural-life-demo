# Rural Life Demo

Godot 4 农村经营游戏 demo。

## 操作

- 移动：`WASD` 或方向键
- 面向农田交互：`E` 或空格
- 鼠标交互：点击底部种子格选择种子，点击农田格开垦/种植/浇水/收获
- 选择种子：`1` 萝卜，`2` 土豆，`3` 白菜，`4` 玉米
- 商店：`B` 打开/关闭种子商店
- 睡觉 / 下一天：`N`
- 出售：`M` 出售背包里的全部成熟作物
- 可选订单：`O` 交付当天订单；不完成订单没有惩罚
- 图鉴：`I` 打开/关闭农场图鉴，只记录种植、收获和收入，不强制作目标
- 保存：`F5` 手动保存
- 读档：`F9` 手动读档；进入游戏时会自动读取上次存档

## 当前循环

1. 开垦空土地。
2. 选择萝卜、土豆、白菜或玉米种子。
3. 在已开垦土地上种植。
4. 每天浇水，按 `N` 进入下一天。
5. 作物成熟后收获。
6. 按 `M` 出售作物，用金币在商店购买更多种子。
7. 有多余作物时，按 `O` 交付可选订单获得额外奖励；不想做可以直接忽略。
8. 按 `I` 查看农场图鉴，回顾自己种过、收过、卖过什么。
9. 按 `F5` 保存进度，下次进入游戏会自动继续。
