# Rural Life Demo

Godot 4 rural management game starter project.

## Controls

- Move: `WASD` or arrow keys
- Interact with farm tile: `E` or `Space`
- Sleep / next day: `N`
- Sell harvested turnips: `M`

## Current Loop

1. Till empty soil.
2. Plant turnip seeds.
3. Water planted crop.
4. Press `N` to advance the day.
5. Harvest mature turnips.
6. Press `M` to sell harvested turnips.
